# Antigravity Master Prompt

Build the complete **DEVOPS & CI/CD PIPELINES — THE CITY THAT SHIPS SOFTWARE** website.

Use the supplied `DESIGN(2).md` as the existing design-system reference, but evolve its UI language
into the natural architectural identity defined in this prompt.

The website must combine:
- premium editorial design
- natural sustainable architecture
- interactive WebGL/Three.js city
- engineering documentation
- CI/CD storytelling

## Primary experience

The user enters a realistic contemporary technology colony.

The city contains six districts:

01 CODE
02 BUILD
03 TEST
04 PACKAGE
05 DEPLOY
06 MONITOR

The user travels through them using scroll, camera movement and interaction.

## Visual identity

Natural daylight, concrete, glass, wood, greenery, roads, bridges, rooftops, utility systems,
realistic vehicles and architectural imperfections.

This is NOT a futuristic city.

Use:
#F4F1EA
#0B0D0E
#A8A6A0
#A3A58A
#B86B4B
#D6B36A

Typography:
Bricolage Grotesque
Figtree
JetBrains Mono

## WebGL

Use React Three Fiber + Three.js + Drei with GLB/GLTF architectural assets.

Create:
DevOpsCity
CityBuilding
PipelineDistrict
PipelineRoute

CityCamera
CityLighting

Use physically believable materials, natural lighting, realistic shadows and atmospheric depth.

Use instancing, LOD, compression, lazy loading and responsive quality levels.

## Pipeline

Represent the CI/CD flow through physical roads, bridges, utility corridors and infrastructure.

Do not use floating arrows.

Each district should be clickable and should move the camera to that part of the city.

## Technical section

Create a dark engineering section with realistic terminal commands.

Create an observability section with:
CPU
MEMORY
REQUESTS
LATENCY
ERROR RATE
UPTIME

## Responsive

Desktop: immersive city.
Tablet: reduced scene.
Mobile: vertical stage journey.
No WebGL: static architectural fallback.

## Engineering quality

Use semantic HTML, accessible controls, keyboard navigation, focus states, alt text and
reduced-motion support.

Audit:
- hierarchy
- responsiveness
- accessibility
- performance
- WebGL memory
- image loading
- layout shifts
- console errors
- broken links
- mobile navigation

Do not create a generic DevOps landing page.

The finished product should feel like an interactive architectural publication about software
infrastructure.

Core statement:

THE CITY THAT SHIPS SOFTWARE.
