# Frontend Website — DevOps & CI/CD Pipelines

Build a premium interactive website around the concept:

**THE CITY THAT SHIPS SOFTWARE**

Combine:
1. the supplied `DESIGN(2).md` UI system;
2. the natural architectural poster identity;
3. an interactive WebGL city.

Do not reproduce the poster as a static webpage. Translate its visual language into an
interactive editorial engineering experience.

## Design foundation

Preserve the useful principles of the supplied design system:
- compact technical metadata
- thin borders
- restrained spacing
- editorial hierarchy
- Figtree for UI/body
- JetBrains Mono for technical information
- subtle hover states
- minimal radius
- controlled motion

Evolve the dark design system into a primarily warm architectural/light interface.
